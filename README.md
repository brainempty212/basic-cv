# Basic CV

A simple single-page Curriculum Vitae website built using semantic HTML.

## Features

- Semantic HTML structure
- SEO meta tags
- Open Graph meta tags
- Favicon
- Single-page CV layout
- Sections for contact information, skills, education, and experience

## Project Structure

```text
basic-cv/
├── index.html
├── README.md
└── images/
    ├── favicon.png
    ├── github.png
    └── linkedin.png
```

## How to Run

Clone this repository:

```bash
git clone https://github.com/brainempty212/basic-cv.git
```

Open the project folder.
Open index.html in a web browser.

You can also use the Live Server extension in Visual Studio Code.
